# MusicRentalAutomation (Windows Forms, C# + PostgreSQL)

Учебное приложение для **автоматизации аренды музыкальных инструментов** в формате Windows Forms с хранением данных в локальном PostgreSQL.

## Что реализовано
- Учёт инвентаря (добавление и просмотр инструментов).
- Бронирование инструмента для клиента.
- Формирование договора на основании бронирования.
- Регистрация платежей по договору.
- Автоматическое создание таблиц в PostgreSQL при запуске.

## Технологии
- C#
- Windows Forms
- .NET (Windows Desktop SDK)
- PostgreSQL (локально)
- Npgsql

## Подготовка PostgreSQL (локально)
1. Установите PostgreSQL и создайте БД `music_rental`.
2. Убедитесь, что пользователь/пароль доступны приложению.
3. По умолчанию приложение использует:
   - `Host=localhost;Port=5432;Database=music_rental;Username=postgres;Password=postgres`
4. При необходимости задайте собственную строку подключения через переменную окружения:
   - `MUSIC_RENTAL_DB`

> SQL-схема находится в `database/schema.sql`.

## Запуск в Visual Studio 2026
1. Откройте `MusicRentalAutomation.sln`.
2. Убедитесь, что PostgreSQL запущен.
3. (Опционально) задайте `MUSIC_RENTAL_DB` в настройках запуска проекта.
4. Запустите проект (`F5`).

## По теме проекта
Если у вас тема «Разработка веб-приложения ...», этот WinForms-вариант можно использовать как desktop-прототип бизнес-логики перед переносом на ASP.NET Core + web frontend.
